# Clubano

Clubano ist eine mandantenfähige Vereinsanwendung für Mitgliederverwaltung, Veranstaltungen, Formulare, Kommunikation und Finanzen.

## Kernbereiche

- Vereinsprofil und Team
- Mitglieder und Mitgliedschaften
- Kontakte
- Veranstaltungen und Eventbuchungen
- Dienstpläne
- Öffentliche Formulare
- Vorlagen, Mail und Brief
- Konten, Buchungen und Rechnungen
- Rollen, Rechte und SaaS-Verwaltung

## Projektziel

Clubano soll Vereinen helfen, den operativen Alltag an einem Ort zu bündeln:

- intern sauber organisiert
- öffentlich sauber getrennt
- mit klarer Mandantentrennung
- mit praxistauglichen Prozessen statt bloßer Verwaltungsoberfläche
