# Schnellstart & Startcenter

Clubano ist so aufgebaut, dass neue Vereine nicht mit einer starren Produkttour beginnen, sondern mit einem **Startcenter** im Dashboard. Das Startcenter zeigt die wichtigsten Schritte in der sinnvollen Reihenfolge an.

## Ziel des Startcenters

Neue Vereine sollen schnell produktiv werden. Clubano hilft dabei mit einer Fortschrittslogik statt mit einer Klick-für-Klick-Tour.

Das Startcenter prüft automatisch:

1. Vereinsprofil vervollständigt
2. Team / Benutzer angelegt
3. Mitgliedschaften angelegt
4. Mitglieder übernommen
5. Konten eingerichtet
6. erster echter Flow gestartet  
   (z. B. Veranstaltung oder öffentliches Formular)

## Empfohlene Reihenfolge für neue Vereine

### 1. Vereinsprofil vervollständigen

Im Bereich **Verein** sollten mindestens gepflegt werden:

- Vereinsname
- E-Mail
- Anschrift
- Vorsitz / Ansprechpartner
- Logo
- Briefbogen (optional, aber sehr sinnvoll)

**Schritt für Schritt**

1. Im Dashboard auf den Schritt **Vereinsprofil vervollständigen** klicken
2. Im Bereich **Verein** Namen, E-Mail und Anschrift eintragen
3. Logo hochladen
4. optional Briefbogen hochladen
5. Änderungen speichern

### 2. Team anlegen

Unter **Benutzer** sollte der Verein weitere Personen anlegen, damit Clubano nicht an einem einzigen Login hängt.

Typische Rollen:

- Vereinsadmin
- Event-Orga
- Kassenverantwortung
- Mitarbeitende mit Leserechten

**Schritt für Schritt**

1. In die **Benutzerverwaltung** wechseln
2. **Neuen Benutzer** anlegen
3. Name, E-Mail und Rolle festlegen
4. Speichern
5. Vorgang für weitere Personen wiederholen

### 3. Mitgliedschaften anlegen

Unter **Mitgliedschaften** werden Beitragsmodelle definiert, zum Beispiel:

- Erwachsene
- Familie
- Jugend
- Fördermitglied

**Schritt für Schritt**

1. **Mitgliedschaften** öffnen
2. neue Mitgliedschaft anlegen
3. Name, Beitrag und Intervall festlegen
4. speichern
5. weitere Mitgliedschaften ergänzen

### 4. Mitglieder importieren oder manuell anlegen

Danach lohnt sich die Übernahme echter Daten:

- Import per CSV
- oder manuelle Anlage einzelner Mitglieder

**Schritt für Schritt**

1. Entscheiden, ob ihr mit Import oder manueller Pflege startet
2. Bei Import: CSV prüfen und Vorschau verwenden
3. Bei manueller Pflege: erstes Mitglied vollständig anlegen
4. Prüfen, ob Mitgliedschaft und Kontaktdaten sauber übernommen wurden

### 5. Konten und Kassen einrichten

Damit der Finanzbereich nutzbar wird, sollten mindestens diese Konten vorhanden sein:

- Vereinskonto
- Barkasse
- optionale Unterkonten

**Schritt für Schritt**

1. **Konten** öffnen
2. Bankkonto anlegen
3. Barkasse anlegen
4. bei Bedarf weitere Konten ergänzen

### 6. Ersten echten Arbeitsbereich aktiv nutzen

Danach entscheidet der Verein, womit er produktiv starten will:

- Mitgliederverwaltung
- Veranstaltungen
- Formulare
- Finanzen

**Schritt für Schritt**

1. Einen ersten praktischen Anwendungsfall wählen
2. Nicht alles gleichzeitig einführen
3. Mit echten Vereinsdaten testen
4. Den Flow im Team kurz abstimmen

## Wenn alle Schritte erledigt sind

Ist das Startcenter vollständig abgeschlossen, kann es:

- eingeklappt
- ausgeblendet
- später wieder eingeblendet

werden.

Damit bleibt das Dashboard hilfreich, ohne später im Weg zu sein.
