# Mitglieder & Kommunikation

Der Mitgliederbereich ist die zentrale Vereinsakte für Personen, Mitgliedschaften, Kommunikation und Datenschutz.

## Mitglieder anlegen

Mitglieder können:

- manuell angelegt
- per Import übernommen
- oder später aus Formularen abgeleitet werden

## Mitglieder manuell anlegen – Schritt für Schritt

1. **Mitglieder** öffnen
2. **Neues Mitglied** anlegen
3. Stammdaten und Adresse pflegen
4. Mitgliedschaft zuordnen
5. Kommunikationsdaten ergänzen
6. speichern

## Mitglieder importieren – Schritt für Schritt

1. Importbereich öffnen
2. CSV hochladen
3. Vorschau kontrollieren
4. Zuordnung der Spalten prüfen
5. Import bestätigen
6. Stichprobe in der Mitgliederliste kontrollieren

## Mitgliedschaft und Beitrag

Mitglieder können einer Mitgliedschaft zugeordnet werden. Clubano speichert dabei einen **Beitrags-Snapshot** am Mitglied, damit sich spätere Änderungen an der allgemeinen Mitgliedschaft nicht ungewollt rückwirkend auswirken.

Gespeichert werden unter anderem:

- Mitgliedschaft
- Beitragshöhe
- Beitragsintervall
- Eintritt
- Austritt
- Kündigung

## Mitgliederakte

Die Mitgliederakte bündelt aktuell:

- Stammdaten
- Mitgliedschaftsdaten
- Tags
- Rechnungen
- Eventbezüge
- Kommunikationshistorie
- Datenschutzstatus

## Kommunikation

Clubano unterstützt bereits:

- Kommunikationsfreigaben
- bevorzugten Kanal
- Kommunikationsprotokolle
- Export von Kommunikationsdaten

Für Mitglieder kann Kommunikation manuell protokolliert werden, zum Beispiel:

- E-Mail
- Telefon
- WhatsApp
- Post

## Kommunikation protokollieren – Schritt für Schritt

1. Mitgliederakte öffnen
2. Bereich **Kommunikation** aufrufen
3. Kanal auswählen
4. Betreff oder Notiz ergänzen
5. Zeitpunkt prüfen
6. Eintrag speichern

## Datenschutz

Im Mitgliedsbereich werden wichtige Datenschutzinformationen geführt:

- Einwilligungen
- Foto-Freigaben intern / öffentlich
- Datenverarbeitungsfreigabe
- Löschvormerkung
- Archivierung statt hartem Löschen

## Datenschutz pflegen – Schritt für Schritt

1. Mitgliederakte öffnen
2. Einwilligungen und Foto-Freigaben prüfen
3. Datum der Einwilligung ergänzen
4. bei Bedarf Löschvormerkung eintragen
5. Änderungen speichern

## Archivierung

Mitglieder werden nicht einfach gelöscht, sondern archiviert. Das schützt die Datenlage und ist für die Vereinsarbeit der deutlich robustere Weg.
