## Dokumentationsprinzip

Die Doku folgt drei Leitlinien:

1. **Aus Vereinssicht schreiben**  
   Nicht primär aus Code- oder Tabellenperspektive, sondern aus Sicht der Menschen, die Clubano im Alltag benutzen.

2. **Klare Trennung von intern und öffentlich**  
   Alles, was nur intern sichtbar ist, wird auch als intern beschrieben. Alles, was öffentlich geteilt oder eingebettet werden kann, bekommt eigene Abschnitte.

3. **Online-taugliche Struktur**  
   Kurze Kapitel, sprechende Dateinamen, relative Links und klare Überschriften. Damit lässt sich die Doku später in ein Docs-Portal oder auf eine Website übernehmen.
